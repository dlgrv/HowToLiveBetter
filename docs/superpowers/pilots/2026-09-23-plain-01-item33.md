## Правило на будущее (как лучше чинить такие места)

1. **Имя химиката** — только через бытовое описание, без «гербицид / herbicide / herbicida»:  
   RU *ядовитое средство от сорняков (паракват)*;  
   EN *toxic weedkiller (paraquat)*;  
   ES *veneno para malas hierbas (paraquat)*.  
   Тест: поймёт ли человек без школы и без садового магазина.

2. **География и имена** — целевая грамматика, не калька с английского:  
   RU *в Бангладеше* / *в больницах Бангладеша*; EN *in Bangladesh*; ES *en Bangladés*.

3. **Процедуры** (промывание, гемосорбция…) — в Benefit; в «простыми словами» только итог для читателя («почти нечем лечить», «лёгкие повреждаются»).

4. **Ритм:** 2–3 коротких предложения лучше, чем один плотный абзац и лучше, чем два сверхкоротких без связки. Смысл: что за вещество → главный процент → второй яд коротко → вывод «жизнь ≠ без последствий».

5. **Где фиксировать:** глоссарий + одна строка в style_rules на язык («never bare drug/chemical names in plain-terms»). Правка пилотов руками, пока не утверждён тон; массовый rewrite — отдельным решением.
