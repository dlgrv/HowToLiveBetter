Privacy

Short description of how optional sign-in works on this site. This is not a formal legal document.

Who

The site is book.dlgrv.com. Interactive account features use the API at api.dlgrv.com. Source: github.com/dlgrv/HowToLiveBetter.

What we collect

Sign-in is optional. If you continue with Google or GitHub, we store the profile PocketBase receives from that provider (typically name, email, username, and avatar URL).

When signed in, we store which recommendations you mark as Useful. The API can also store bookmarks and reading position; those may be used as features expand.

Without signing in, the book itself is readable; the browser may keep UI preferences and a temporary reading position locally.

Where it lives

In the browser: auth token and profile cache, theme/language/layout prefs in localStorage; last reading anchor in sessionStorage.

On the server: account and feature data in SQLite behind api.dlgrv.com (self-hosted PocketBase).

Cookies

The book site does not set first-party tracking or advertising cookies. Session and prefs for the account UI use browser storage, not cookies on book.dlgrv.com.

During OAuth, Google or GitHub may set their own cookies on their domains. That is outside this site.

Third parties

Google and GitHub for sign-in only. There are no analytics or ad scripts embedded in the book pages.

Book text vs account data

The guide text is Public Domain (Unlicense). Your account data is separate and is not part of that dedication.

Contact and deletion

To ask about your account or request deletion, open an issue on github.com/dlgrv/HowToLiveBetter/issues.
