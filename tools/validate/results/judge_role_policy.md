# Итоговая роль судьи (GLM-5.3-Flash) в пайплайне качества

Дата: 2026-09-21. Основание: три слепых прогона (lite, lite2, lite3).

## Экспериментальная база

| Прогон | Что мерили | Результат |
|---|---|---|
| lite (36 вызовов) | смешанный сет (уточнения/шум/твины) | 36/36 против ключа на механике, 0/36 за длинный вариант |
| lite2 (120 вызовов) | abridgement (стиль) + bloat (раздувание) + 42 decoy | decoy FP 0/42; против ключа 8/12; κ(судья, человек) = 0.000 на 12 совместных решениях |
| lite3 (18 вызовов) | meaning_break: инверсии смысла (право↔обязанность, направление↔запрет, выше↔ниже) | **14/14 за оригинал**, 6/6 пар стабильны по порядку, unparsed 4/18 (все на паре g02) |

## Вывод: операционный диапазон судьи

- **НЕ умеет** judge'ить естественность/стиль: на абляциях стиля его выбор
  антикоррелирует с человеком (κ=0.0), на слабом раздувании тянется к
  короткому. Автогейт по «вкусу» судьи запрещён.
- **Умеет** ловить поломку смысла: surgical-инверсии фактов и логики
  детектируются 14/14 при нулевом order bias. Механическая санитария
  идеальна: decoy FP 0/42 (граница ≤3.6%), short-bias отсутствует на
  meaning_break.

## Правило для пайплайна (решение Лёни, 2026-09-21)

1. **Судья — только офлайн-инструмент.** В пайплайн НЕ вживляется
   (никакого pass D, никакой колонки в status.py): пайплайн работает
   без AI API целиком. Проверка смысла судьёй запускается ВРУЧНУЮ на
   финальной вычитке.
2. Автогейт = детерминированные линты (байт-гейты, цифры, защищённые
   строки, длина) + выборочная человеческая разметка золотых пар.
3. Prompt судьи не менять под естественность — это вне его чувствительности.
4. unparsed-вызовы считать «не решено» (не зачитывать ни одной из сторон);
   при >20% unparsed на паре — пара исключается из судейских метрик.
5. Существующий factcheck (pass E) остаётся как есть: advisory-колонка fc:
   в status.py, без ключа — SKIP, не блокирует. (Вариант вынести E из
   пайплайна был отклонён.)

## Как запустить проверку смысла вручную

```bash
# одна юнит-карточка (source-grounded фактчек CN↔перевод):
export $(grep -E "^ZAI_API_KEY=" ~/.hermes/.env | head -1)
python3 tools/validate/judge.py --file book/ru/08-Не-подставляйтесь.md --mode factcheck --json

# слепая проверка на деградациях (валидация судьи, не для книги):
python3 tools/validate/judge_blind_run.py --subset <subset.json> \
  --override <degradations.json> --out <outdir> --workers 4
```

Интерпретация: судья надёжен как «детектор поломки смысла» (14/14 на
lite3), его вердикт — рекомендация для человека, не гейт.

Файлы: `golden_judge_run_lite*/`, `golden_judge_lite3_verdict.json`,
`golden_kappa_verdict_lite2.json`, рецепт `_lite3_degrade_meaning_break.json`
(строится `build_lite3.py`, гейты `check_degrade.py`).
